SNAKE MOD LIVE - QUICK START
============================

1. Install Node.js 20 or newer from https://nodejs.org/
   (Choose the LTS installer and keep "Add to PATH" checked.)

2. Double-click start.bat in this folder.
   The game opens in your browser. If it does not, open:
   http://localhost:3000/

3. Click Play (or press Space).

4. To stop the app, close the "Snake Mod Live Server" window.

TikTok is optional. The game works offline. Use Menu > TikTok > Gift lab
or Demo mode to test gift effects without going live.

OBS browser source:
   http://localhost:3000/?obs=1&autoplay=1

Port 3001 instead of 3000:
   Open Command Prompt in this folder and run:
      set PORT=3001
      start.bat

For the full manual, gift mapping, settings, OBS notes and troubleshooting,
open README.md (it is a plain-text file you can read in Notepad).
